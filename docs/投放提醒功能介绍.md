# 投放提醒与告警配置功能介绍

## 一、功能定位

投放提醒用于定时检查投放对象的数据表现，并在满足告警条件时生成可追溯的规则报告。当前功能由两部分组成：

- **媒介管理 → 告警配置**：创建和管理企业模板、实际运行规则。这里只负责配置，不展示具体命中素材。
- **数据投放 → 投放提醒**：查看规则执行记录、执行明细和命中素材，并进一步打开素材表现详情执行后续操作。

站内提醒不再单独建设一套通知列表。投放提醒页的规则报告就是站内结果中心，左侧铃铛只承担未读红点或数量提示。企业微信作为可选外部通知渠道，使用创作平台统一消息格式。

## 二、核心概念

- **企业模板**：管理员维护的可复用配置起点。模板预设媒介平台、报表 / 素材类型、提醒类型、判断条件、运行时间和企业微信设置，不绑定具体公司、广告主或素材。
- **规则**：真正参与定时执行的业务配置。规则必须绑定创建者有权使用的公司、广告主和素材范围。
- **复用**：从企业模板带入配置并生成一条当前用户自己的规则。复用后可修改条件、时间、范围和企业微信设置。
- **规则执行记录**：一条规则在最近演示执行时间的结果汇总，包含检查素材、命中、未命中、数据不足和执行状态。
- **执行明细**：某条执行记录的详细证据，包含条件、范围、命中素材和未命中 / 数据不足结果。
- **数据不足**：当前数据不能可靠完成判断，例如字段缺失、数据延迟、统计窗口不完整或只有历史数据。数据不足不会生成待处理事件，但会保留在执行记录中。

模板只是快速配置起点，不是持续控制规则的父级。规则保存后按自己的配置独立运行；模板停用或删除只会停止后续复用，不会暂停或删除已经生成的规则。

## 三、三层权限架构

| 能力 | 一级管理员 | 二级管理员 | 成员 |
| --- | --- | --- | --- |
| 查看模板和规则 | 全组织 | 自己及所管成员 | 自己 |
| 新增企业模板 | 可以 | 可以 | 不可以 |
| 新增规则 | 有素材权限即可 | 有素材权限即可 | 有素材权限即可 |
| 复用模板 | 所有可见模板 | 上级共享或自己创建的模板 | 管理员共享模板 |
| 编辑模板 / 规则 | 全组织 | 仅自己创建 | 自己的全部规则，包括复用规则 |
| 开关模板 / 规则 | 全组织 | 自己及所管成员 | 自己的全部规则 |
| 删除模板 / 规则 | 全组织 | 仅自己创建 | 自己的全部规则 |

权限只决定用户能看到和操作哪些配置，不会扩大广告主或素材数据范围。复用模板时，只能绑定当前用户本来就有权访问的数据。

## 四、入口与页面关系

    用户菜单
    └─ 媒介管理
       └─ 告警配置
          ├─ 模板视图
          │  ├─ 新增 / 编辑企业模板
          │  ├─ 查看成员使用情况
          │  └─ 复用 → 生成独立规则
          └─ 规则视图
             ├─ 新增 / 编辑规则
             ├─ 查看广告主账户范围

    数据投放
    └─ 投放提醒
       ├─ 规则执行记录
       ├─ 查看执行明细（抽屉）

高保真中的“角色视角 / 预览身份”仅用于演示不同权限，正式产品以当前登录账号为准。

## 五、告警配置列表

### 1. 模板 / 规则切换

- **模板**：显示可复用的企业模板。新增企业模板按钮只在管理员视角显示。
- **规则**：显示实际运行规则。所有拥有素材权限的用户都可以新增规则。
- 切换视图后，搜索和筛选按当前视图重新计算。

### 2. 筛选区

- **搜索框**：搜索模板 / 规则名称和条件文案。
- **媒介平台**：筛选巨量 AD、巨量千川、巨量本地推。切换平台后广告主筛选恢复为全部。
- **广告主账户**：仅规则视图显示，支持搜索当前用户有权的账户。
- **创建日期**：支持全部时间、近 7 天、近 30 天。它筛选创建时间，不改变规则生效日期。
- **提醒类型**：支持全部、异常、机会、起量、自定义。
- **点击空白处**：关闭当前打开的筛选下拉，不清空已选值。

### 3. 模板列表信息

- **开关**：控制模板是否可以继续被复用。关闭模板不影响已生成规则。
- **企业模板**：显示模板名称、提醒类型标签和条件摘要。
- **平台与报表 / 素材类型**：平台下方展示模板覆盖的报表类型和真实素材类型；千川不会把报表类型混写成素材类型。
- **创建日期 / 创建者**：用于审计模板来源。
- **成员使用情况**：显示使用人数和生成规则数。点击后打开抽屉，按成员展示其生成的规则。
- **提醒去向**：站内规则报告，以及可选的企业微信。
- **状态**：可复用或已停用。
- **编辑**：进入企业模板表单。
- **复用**：带入模板配置，进入规则表单并选择自己的业务范围。
- **删除**：只删除模板本身；已有规则继续独立运行。

### 4. 规则列表信息

- **开关**：开启或暂停规则。暂停后停止后续检查，历史执行记录保留。
- **规则**：显示名称、提醒类型和条件摘要。
- **媒介平台**：说明规则使用哪一个平台的数据口径。
- **广告主账户**：显示覆盖账户数量。点击后打开抽屉，按公司分组展示具体账户。
- **创建日期 / 创建者**：用于识别规则归属。
- **素材范围**：显示全部素材或指定素材数量。
- **提醒去向**：规则报告，以及可选的企业微信。
- **状态**：运行中、已暂停或已过期，并展示运行频率和生效范围。
- **编辑**：进入当前规则表单。成员复用模板生成的规则也可编辑。
- **删除**：停止后续监控；历史规则报告继续保留。

### 5. 使用边界说明

点击后打开抽屉，解释当前角色、三层权限、模板与规则的区别、复用流程和删除影响。关闭按钮、遮罩空白处和 Esc 均返回原列表，保留筛选和滚动位置。

## 六、新建、编辑与复用表单

### 1. 媒介平台

规则和模板一次选择一个媒介平台。切换平台会重新计算平台专属的报表、素材类型、指标和业务范围，并移除不兼容的旧选择。

### 2. 巨量千川报表与素材类型

千川使用两层范围，不能把报表类型和素材类型混在一起：

1. **千川报表类型**：全域素材、全域直播间、全域商品、标准素材、标准直播间画面。默认全选，可多选。
2. **素材类型**：根据已选报表动态显示。
   - 全域素材：标题、视频。
   - 标准素材：标题、图片、视频。
   - 全域直播间、全域商品、标准直播间画面：按报表对象直接判断，不需要二级素材类型。

当只选择直播间、商品等报表时，素材类型区域显示“无需选择素材类型”，不会出现空的 0 / 0 选择器。

### 3. 公司、广告主与素材范围

- **公司**：全部有权公司或指定公司。指定公司后只展示对应广告主。
- **广告主**：全部有权广告主或指定广告主。指定模式使用双栏选择器，左侧搜索与勾选，右侧保留已选项。
- **素材**：全部素材或指定素材。全部素材会自动纳入以后进入该公司和广告主范围的新素材。
- **素材搜索**：按素材名称或 ID 搜索，不清空已选素材。
- **全选本页**：只影响当前搜索结果的当前页，最多选择 100 条素材。
- **分页**：上一页 / 下一页不会丢失搜索词和已选素材。
- **清空 / 移除**：清理全部或单个已选项，同时维护公司、广告主、素材的上下级有效性。

模板不展示公司、广告主和素材范围；这些范围在复用模板生成规则时再选择。

### 4. 规则设置

- **模板名称 / 规则名称**：用于列表、规则报告、执行明细和企业微信消息中的统一识别，最多 50 个字。
- **提醒类型**：异常、机会、起量、自定义。自定义类型需要填写名称，所有自定义类型使用统一的自定义标签颜色。
- **判断条件**：统计周期、指标、运算符和阈值组成一条条件。多条条件为“且”关系，全部满足才命中。
- **新增告警条件**：最多 8 条。
- **删除条件**：至少保留一条，最后一条不能删除。
- **悬浮问号**：解释功能口径和存在原因，不改变数据；提示层必须位于页面内容上方。

### 5. 运行时间

- **每 30 分钟**：每半小时检查一次。
- **每小时**：每小时检查一次。
- **固定时间**：通过时间选择器设置每日执行时间。
- **长期有效**：规则持续生效，直到被关闭或删除。
- **指定日期**：使用日历范围选择器设置开始和结束日期，并可使用近 7 / 30 / 90 天快捷项。

### 6. 提醒与通知

- **站内规则报告**：默认开启且无需配置消息内容；命中和未命中结果统一进入投放提醒页。
- **企业微信**：可选。勾选后必须填写 Webhook 地址和企业微信 ID。
- **消息格式**：企业微信使用创作平台统一告警格式，自动带入平台、广告主、素材、提醒类型、命中值和时间，管理员和成员不需要额外编辑通知模板。

### 7. 表单操作

- **提交规则 / 保存企业模板**：校验必填项并保存，成功后返回对应列表。
- **试运行**：只对规则显示。按当前数据快照计算命中、未命中和数据不足，不保存规则，也不发送通知。
- **取消 / 返回列表**：放弃未保存修改，返回原列表。

## 七、投放提醒与规则报告

投放提醒页只保留规则报告，不再单独设置“提醒动态”“观察记录”或站内通知预览，避免同一结果在多个栏目重复出现。

### 1. 汇总信息

- **执行规则数**：当前可见范围内参与本次演示检查的规则数量。
- **检查素材**：所有规则实际参与判断的素材数量。
- **命中提醒**：满足全部条件的素材数量。
- **未命中**：数据完整，但没有满足全部条件的素材数量。
- **数据不足**：本次无法可靠判断的素材数量。

### 2. 执行记录筛选

- **媒介平台**：按平台筛选，并重置广告主账户。
- **广告主账户**：搜索或选择当前平台下的账户。
- **创建日期**：按规则创建时间筛选。
- **搜索框**：搜索规则、素材名称或素材 ID。
- **提醒类型**：全部、异常、机会、起量、自定义。
- **执行结果**：全部、有命中提醒、无命中、含数据不足、未执行。

### 3. 执行记录列

每条记录展示规则名称与条件、执行时间、提醒类型、检查素材、媒介平台、命中、未命中、数据不足、执行状态和操作。

- **已执行**：本次规则已经完成检查。
- **未执行**：规则暂停、超出生效日期或当前没有可检查素材。
- **查看执行明细**：打开抽屉，不跳离投放提醒页。

### 4. 执行明细抽屉

抽屉展示规则条件、平台、运行时间、检查数量以及命中 / 未命中 / 数据不足分布。命中素材以列表呈现：

- **点击素材名称 / 查看素材表现**：在右侧打开复用自素材表现页的单条素材详情。
- **进入爆款工厂**：带入当前素材进入爆款相关流程。
- **加入素材库**：带入当前素材进入素材库。
- **关闭素材详情**：回到执行明细，保留当前规则上下文。
- **关闭执行明细**：回到原执行记录列表，保留筛选和滚动位置。

## 八、企业微信通知预览

投放提醒页提供“企业微信通知预览”，只展示系统默认的企业微信消息结构，不提供站内通知格式配置。

预览内容包括提醒类型、规则名称、平台、广告主账户、素材名称、命中指标和触发时间，并提供“查看素材表现”入口。关闭按钮或点击遮罩空白处返回规则报告。

## 十、设计与交互原则

- 配置和执行结果分开：后台只做告警配置，具体素材只在投放提醒中查看。
- 一个功能只保留一个明确入口，不重复放置规则报告或关闭按钮。
- 详情统一使用右侧抽屉，减少页面来回跳转造成的操作疲劳。
- 搜索、筛选和分页不清空已选公司、广告主或素材。
- 平台、公司、广告主、素材逐级联动，移除上级范围时自动清理无效下级选择。
- 报表类型与素材类型必须分层表达，尤其是巨量千川。
- 所有展示信息都先说明“是什么”，再说明“为什么存在”，最后说明“点击后去哪”。
